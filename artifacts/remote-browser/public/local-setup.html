Run Chromium on your computer

The website stays on Render. Express, Chromium, and the display run on your Windows computer through WSL 2 and a temporary Cloudflare Tunnel.

The free Quick Tunnel URL changes when restarted. Paste the new URL into Set up local browser connection on the sign-in page. Keep the local API and tunnel running while browsing.

1. Install WSL 2

Open PowerShell as Administrator and run:

wsl --install -d Ubuntu

Restart if Windows asks, then open Ubuntu and complete its first-run setup.

2. Install Linux packages and clone the private repository

Install Node.js 24 and the GitHub CLI using their official Linux instructions before running these commands.

sudo apt update
sudo apt install -y xvfb x11vnc openbox curl git
gh auth login
gh repo clone fartingmaster9999/nexobrowser
cd nexobrowser
corepack enable
pnpm install --frozen-lockfile

Keep the repository under Ubuntu's home folder rather than /mnt/c.

3. Install Chromium and create local account settings

cd tools/browser-worker
npm install
npx playwright install --with-deps chromium
cd ../..
cp tools/local-browser/.env.local.example .env.local

Edit .env.local. Enter your approved email, a long unique password, and a random session secret. Generate the secret with openssl rand -hex 32. Keep this file private; it is ignored by Git.

4. Start the browser desktop

In Ubuntu terminal 1, from the repository root:

bash tools/local-browser/start-desktop.sh

In Ubuntu terminal 2:

cd tools/browser-worker
npm run start:desktop

5. Start the API and free tunnel

In Ubuntu terminal 3, from the repository root:

bash tools/local-browser/start-api.sh

Install cloudflared in Ubuntu using Cloudflare's official instructions. In Ubuntu terminal 4:

cloudflared tunnel --url http://127.0.0.1:8080

Copy the HTTPS trycloudflare.com address printed by the command.

6. Connect the website

  1. Return to the sign-in page and choose Set up local browser connection.
  2. Paste the tunnel's HTTPS URL and save.
  3. Sign in with the local email and password, then choose Open browser.

On later restarts, paste the new tunnel URL. The browser profile remains in ~/.nexo-browser/chromium-profile.

Stop the local browser

Press Ctrl+C in the Chromium and API terminals, stop the tunnel, then run:

bash tools/local-browser/stop-desktop.sh

The VNC port is loopback-only. The public tunnel does not expose it directly; the browser view uses a short-lived single-use ticket issued after sign-in.
